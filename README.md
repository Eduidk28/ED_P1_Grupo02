# ✈️ Sistema de gestión de vuelos y rutas aéreas

Aplicación académica desarrollada como proyecto de la asignatura **Estructura de Datos** de la Escuela Superior Politécnica del Litoral (ESPOL).

El proyecto permite administrar información de países, aeropuertos y vuelos, además de consultar conexiones y calcular rutas más cortas entre diferentes aeropuertos.

## 🎯 Objetivo

Aplicar los conocimientos de estructuras de datos y algoritmos mediante el desarrollo de una aplicación que permita representar y gestionar conexiones entre aeropuertos.

## ⚙️ Funcionalidades principales

- Registro y gestión de países.
- Administración de aeropuertos asociados a los países.
- Registro de vuelos y conexiones entre aeropuertos.
- Consulta de conexiones aéreas.
- Cálculo de rutas más cortas entre aeropuertos.

## 🛠️ Tecnologías y herramientas

- Java.
- Gradle.
- IntelliJ IDEA.
- Git y GitHub.

## 📚 Contexto académico

Proyecto realizado en equipo como parte de las actividades prácticas de la asignatura Estructura de Datos en ESPOL.


## 📂 Estructura del proyecto

El repositorio contiene los archivos de configuración de Gradle y los directorios correspondientes al código fuente de la aplicación.

## 🚀 Ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/Eduidk28/ED_P1_Grupo02.git
   ```

2. Abrir el proyecto desde un entorno de desarrollo compatible con Gradle.

3. Esperar a que Gradle configure las dependencias del proyecto.

4. Ejecutar la aplicación desde la clase principal correspondiente.
